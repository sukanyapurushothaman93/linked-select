# linked-select

Strapi 5 project with a local **linked-select** plugin: cascading parent/child dropdowns for the Content Manager.

See [`src/plugins/linked-select/README.md`](src/plugins/linked-select/README.md) for setup and usage.

## Getting started

### `develop`

Start Strapi with autoReload enabled.

```
npm run develop
# or
yarn develop
```

### `start`

Start Strapi with autoReload disabled.

```
npm run start
# or
yarn start
```

### `build`

Build the admin panel.

```
npm run build
# or
yarn build
```
